# jupyterlauncher
Simple batch script to start virtual env and start jupyterlab.

Enter your needed libraries in the code and the script will install them if they are not already installed in your env.

Oh, and also will install JupyterLab if you somehow managed to forget that...

After following the install advice on https://bodo-schoenfeld.de/jupyter-lab-und-jupyter-notebook-unter-windows-installieren/
